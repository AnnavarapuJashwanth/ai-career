# Render Backend Deployment Guide

## 🚀 Quick Deploy to Render

### Step 1: Prepare Your Repository
✅ Code pushed to GitHub: https://github.com/AnnavarapuJashwanth/ai-career

### Step 2: Deploy the Frontend to Netlify

1. In Netlify, create a new site from the GitHub repository.
2. The root `netlify.toml` sets the base directory to `frontend` and configures the Vite build.
3. Deploy once to get the site's exact `https://<site-name>.netlify.app` origin.

### Step 3: Create the Backend Service on Render

1. Go to [Render Dashboard](https://dashboard.render.com/).
2. Create a **Web Service** from `AnnavarapuJashwanth/ai-career`.

### Step 4: Configure Service Settings

**Basic Settings:**
- **Name**: `careerai-backend` (or any name you prefer)
- **Region**: Oregon (US West) - or closest to your users
- **Branch**: `main`
- **Root Directory**: *(leave empty - deploy from repo root)*

**Build & Deploy:**
- **Runtime**: `Python 3`
- **Build Command**: 
  ```bash
  cd backend && pip install --upgrade pip && pip install -r requirements.txt
  ```
- **Start Command**: 
  ```bash
  python -m uvicorn backend.main:app --host 0.0.0.0 --port $PORT
  ```

**Instance Type:**
- Select **Free** (512 MB RAM, 0.1 CPU)
- ⚠️ Note: Free instances spin down after inactivity

### Step 5: Environment Variables

Click **"Advanced"** and add these environment variables:

| Key | Value | Notes |
|-----|-------|-------|
| `MONGODB_URI` | Set privately in Render to the Atlas connection URI for database `careerai` | Create an Atlas database user with only the permissions the app needs; never commit this URI |
| `GEMINI_API_KEY` | Set in Render if using Gemini features | From Google AI Studio |
| `RAPIDAPI_KEY` | Set in Render if using RapidAPI features | Optional |
| `JWT_SECRET` | Generated by the Render blueprint | Keep this secret |
| `ALLOWED_ORIGINS` | `https://<site-name>.netlify.app` | Use the exact Netlify site origin; comma-separate any additional trusted origins |
| `PYTHONPATH` | `/opt/render/project/src` | Set by `render.yaml` |

### Step 6: Deploy

1. Click **"Create Web Service"**
2. Wait 5-10 minutes for initial build
3. Note your backend URL: `https://careerai-backend.onrender.com`

### Step 7: Test Backend

Once deployed, test these endpoints:

```bash
# Health check
curl https://careerai-backend.onrender.com/

# Should return: {"service":"careerai","status":"ok"}
```

## 🔧 Troubleshooting

### Build Fails
- Check logs in Render dashboard
- Ensure all dependencies in `requirements.txt` are compatible
- Python version defaults to 3.11 (compatible with your code)

### Import Errors
- Verify `PYTHONPATH=/opt/render/project/src` is set
- Ensure all imports use `backend.` prefix (already fixed)

### MongoDB Connection Fails
- Confirm the Atlas cluster hostname resolves and the URI is copied from Atlas's **Connect → Drivers** flow.
- Confirm Atlas Network Access allows Render and the database user has access to `careerai`.
- Keep the connection URI only in Render's environment settings; never commit it or put it in Netlify.

### App Sleeps (Free Plan)
- Free instances spin down after 15 min of inactivity
- First request after sleep takes 30-60 seconds
- Upgrade to Starter ($7/month) for always-on

## 📊 Connect Netlify to the Backend

**Next Steps:**
1. Set `VITE_API_URL` in the Netlify site's environment variables to `https://YOUR-SERVICE.onrender.com/api`.
2. Set `ALLOWED_ORIGINS` in Render to the exact Netlify site origin, then redeploy the backend.
3. In Atlas Network Access, allow the Render service's outbound IP addresses. If you use `0.0.0.0/0`, use a strong unique database password and a least-privilege database user.
4. Set `MONGODB_URI` in Render to the correct Atlas URI; do not put credentials in frontend variables.
5. Trigger a new Netlify deploy so the frontend is built with its production API URL.

**Important URLs:**
- Render Dashboard: https://dashboard.render.com
- Your Backend: `https://YOUR-SERVICE.onrender.com`
- API Docs (after deploy): `https://YOUR-SERVICE.onrender.com/docs`
